# Li Xu — Personal Website

基于简历制作的个人网站，适用于 GitHub Pages。不需要安装依赖或运行构建命令。

## 上传方法

1. 解压 `Li-Xu-GitHub-Pages.zip`。
2. 在 GitHub 的上传页面点击 **choose your files**。
3. 选择解压后的 `index.html`、`resume.html`、`favicon.svg`、`README.md` 四个文件。直接放到仓库根目录，不要把整个 website 文件夹作为一层目录上传，也不要只上传 ZIP。
4. 点击 **Commit changes**。
5. 在仓库 **Settings → Pages** 中，将 Source 设为 **Deploy from a branch**，Branch 选择 **main**，文件夹选择 **/ (root)**，点击 **Save**。
6. 等待 GitHub Pages 部署完成后，访问 https://lonelyboy627.github.io/ 。如果刚上传后没有变化，等待部署完成并刷新页面。

## 文件说明

- `index.html`：首页，包含全部样式和交互，支持手机和电脑。
- `resume.html`：公开版简历页面，可点击 Print / Save as PDF 打印或保存 PDF；未包含电话号码。
- `favicon.svg`：网站图标。
- `README.md`：本说明。

双击 `index.html` 可以先在电脑上预览。邮箱复制功能在 HTTPS 网站上使用；本地预览可直接点击邮箱发送邮件。
